# ResultModel 与 Azrng 异常体系统一

- 本次目标：将数据库主服务 `IDatabaseService` 的元组返回契约统一为 Azrng.Core `IResultModel<T>` / `ResultModel<T>` 语义，并联动服务层与 ViewModel 调用方。
- 核心改动：
  - 将 `IDatabaseService` 及 `DatabaseService` 的 16 个服务方法从 `(bool Success, ..., string Message)` 改为 `IResultModel<T>`。
  - 为连接测试、SQL 执行和表统计等多字段返回新增专用结果记录。
  - 新增数据库结果包装 helper，失败结果统一通过 Azrng.Core `ResultModel<T>.Failure(...)` 承载。
  - 更新导出负载、代码生成负载、数据库浏览、详情、连接管理、SQL 查询和导出弹窗调用方。
  - 更新相关数据库服务测试替身与断言。
- 修改文件：
  - `AzrngTools/Services/Database/IDatabaseService.cs`
  - `AzrngTools/Services/Database/DatabaseService.cs`
  - `AzrngTools/Services/Database/DatabaseServiceResults.cs`
  - `AzrngTools/Services/Database/DatabaseResultModel.cs`
  - `AzrngTools/Services/Database/DatabaseResultModelExtensions.cs`
  - `AzrngTools/Services/Database/CodeGenerationPayloadService.cs`
  - `AzrngTools/Services/Database/DatabaseExportPayloadService.cs`
  - `AzrngTools/ViewModels/Database/*`
  - `AzrngTools.Tests/Services/Database/*`
- 校验情况：
  - 已执行：`dotnet build AzrngTools.sln -v minimal`，通过。
  - 已执行：`dotnet test AzrngTools.Tests\AzrngTools.Tests.csproj --filter "FullyQualifiedName~AzrngTools.Tests.Services.Database|FullyQualifiedName~AzrngTools.Tests.ViewModels.Database" -v minimal`，47 个数据库相关测试通过。
  - 已执行：`dotnet test AzrngTools.sln -v minimal`，未全量通过；失败项为既有 `DebouncedActionDispatcherTests.Debounce_executes_only_latest_action_after_delay` 时序断言，与本次数据库服务契约变更无直接关系。
- 风险或遗留项：
  - 本轮已完成数据库主服务返回契约统一；其它非数据库工具服务仍可按后续切片继续对齐。
  - 当前 Azrng.Core 成功工厂返回默认消息，若后续需要保留每个成功消息为 ResultModel.Message，需要确认是否升级/扩展 Azrng.Core API 或引入本地包装策略。
