# 数据库工作台左侧选择体验修复

## 本次目标
- 修复导出文档弹窗左侧架构较多时撑高窗口，导致底部导出按钮被遮挡且对象树无法滚动的问题。
- 支持数据库工作台左侧数据库下拉输入搜索，便于数据库较多时快速定位。
- 修复连接管理中输入用户名和密码后刷新数据库列表时，PostgreSQL 误连到不存在默认库导致报错的问题。
- 移除连接管理弹窗外层重复标题，保留弹窗内部标题区域。
- 走查连接管理的“测试连接 / 刷新 / 保存 / 连接”逻辑，统一各按钮的校验职责。
- 修复编辑已有连接只修改密码等字段时误提示“连接名称已存在”的问题。
- 修复连接管理左侧底部删除按钮显示被裁切的问题。
- 修复编辑已有连接后点击“测试连接”仍被连接名称重复校验拦截的问题。

## 核心改动
- 将导出文档弹窗高度约束在 620，避免对象树内容把不可调整大小的弹窗撑出可视区域。
- 为弹窗中间内容区、左侧导出对象卡片和树容器补充 `MinHeight="0"`，允许星号行按可用高度收缩。
- 为左侧对象树滚动容器启用自动纵向滚动并关闭滚动链，滚动限定在对象树内部。
- 为数据库工作台主 ViewModel 增加数据库筛选文本与过滤后的数据库集合，输入搜索只过滤下拉项，不直接切换当前数据库。
- 将左侧数据库选择框改为可输入模式，输入内容绑定筛选文本，选择过滤结果后仍通过原有 `SelectedDatabaseName` 流程切库。
- 数据库列表加载改为使用 catalog 连接配置；PostgreSQL 列库时优先连接 `postgres`，避免默认库为空或不存在时拿用户名库触发连接失败。
- 打开连接管理弹窗时不再传入外层 Dialog 标题，避免与弹窗内部“连接管理”标题重复。
- 测试连接改为使用 catalog 连接配置验证服务器与凭据，不再要求默认数据库已填写；保存和连接仍要求默认数据库，保证进入工作台后有明确业务库上下文。
- 默认数据库提示文案调整为“保存或连接前需要选择默认数据库”，减少刷新前的误导。
- 增加 `InternalsVisibleTo` 以覆盖服务层 catalog 配置和连接弹窗校验职责的单元测试。
- 连接管理弹窗打开时会按连接名称、类型、主机、端口和数据库匹配到已保存列表内的真实对象，避免外部传入等价但不同引用的连接时被重名校验误判。
- 左侧底部删除按钮从 emoji 图标改为明确的“删除”文字按钮，并增加固定高度和列间距，避免字体裁切造成按钮内容被遮挡。
- 表单校验增加连接名称唯一性开关；测试连接只验证连接名非空、服务器、端口、凭据和可选数据库，不再检查名称是否重复，保存和连接仍保留重名校验。
