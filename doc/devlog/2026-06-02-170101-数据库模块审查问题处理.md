## 核心改动

- 修复 `DatabaseService.MapDatabaseType` 对达梦和未知数据库类型静默映射为 SQL Server 的问题，改为明确返回不支持错误。
- 补充导出对象类型映射，支持表、视图、存储过程三类节点的防御性转换。
- 删除连接对话框 Legacy 校验死代码，清理重复的 `ShowDatabaseSelector` 属性通知。
- 保存和导出连接配置时改为序列化加密副本，不再对内存中的连接密码做原地加解密。
- 连接上下文初始化、数据库切换、表 / 视图 / 存储过程详情自动加载改为安全调度，异常会进入日志和界面状态。
- 抽出 `IDatabaseService`，让 `DatabaseService` 通过 `ISingletonDependency` 注册，并将数据库工作台主 ViewModel 与子 ViewModel 改为构造注入共享服务实例。
- 在审查报告中补充 2026-06-02 处理状态，区分已处理、需专项和暂不处理项。
- 补充数据库服务、导出对象映射、连接加密副本和 DI 注册单元测试。
