# PDF 管理设计（DES-PDF-001）

> 本文档为依据当前实现整理的回溯基线，待用户确认后转为 approved。

## 需求追溯

- 关联需求：`REQ-PDF-001`。
- 本次覆盖：PDF 载入、页码范围解析、分割导出与 Word 导出（含 2026-10-30 确认的 Word 还原度升级：字号 / 加粗、位图图片、有线表格）。
- 不覆盖：合并、加密、水印、OCR、无线表格与多栏版面分析等范围外能力。

## 契约引用

- 页选择与导出请求 / 结果模型以 `Models/Pdf/` 下类型为最终事实来源。

## 技术设计

### 模块职责

| 模块 | 职责 |
| --- | --- |
| `PdfManagementPageViewModel` | 页面向导编排：文件载入、范围输入、导出命令、结果反馈 |
| `AsposePdfProcessingService` | PDF 处理内核：分割（PdfSharp 写出）与 Word 转换（PdfPig 读取 + NPOI XWPF 写出）。类型名为历史遗留（2026-09 起已无 Aspose 依赖，改名涉及 DI 与测试联动，不做无关重构） |
| `PdfPageRangeParser` | 纯静态解析器：把范围表达式解析为页码集合，失败返回明确原因，不抛异常 |

### 页码范围解析规则

- 表达式由逗号分隔，段为单页（`3`）或区间（`3-5`）；
- 解析结果用有序集合去重、排序后输出；
- 页数无效、表达式为空、格式非法等情形返回失败结果并携带可读原因（如"请输入页码范围""当前 PDF 页数无效"），由页面直接展示。

### 数据流向

```text
选择本地 PDF → 读取页数
        ↓ 输入范围表达式
PdfPageRangeParser.Parse(表达式, 页数)
        ├── 失败 → 展示原因，流程终止
        └── 成功 → 页码集合
                    ↓
        AsposePdfProcessingService
          ├── 分割导出 → 输出新 PDF
          └── Word 导出 → 输出 docx
                    ↓
        结果反馈（成功 / 失败原因）
```

### 关键技术决策

1. **读取与写出库选型（2026-09 更新）**：PDF 读取用 PdfPig（NuGet，取词带字体与坐标信息），Word 输出用 NPOI 自带 XWPF（与 Excel 导出共用 NPOI，不再引入独立依赖）；分割写出用 PdfSharp。原"本地 Aspose DLL + 授权文件"方案已废弃。
2. **解析与处理分离**：范围解析失败在进入处理内核前短路，避免无效处理；解析器为纯函数，便于单元测试。
3. **失败包装统一**：处理内核异常统一转 `IResultModel` 失败结果并写日志，不向页面抛异常。

### Word 导出还原度升级设计（2026-10-30）

在既有"取词 → 按行聚类 → 逐段写出"管线上增加三个还原层，逐页处理，未命中增强条件的页面完全回落到旧行为（回归安全）：

```text
每页：
  words（含字体信息） ──┐
  表格线（内容流路径） ──┼──▶ 版面块列表（按 y 排序）──▶ 依序写出 docx
  位图图片 ────────────┘
```

1. **字号与加粗**：取词时保留 `Letter` 的字体信息（`FontDetails.IsBold`、`FontSize`，单位磅），同一行内相邻同样式词合为一个 run，逐 run 直接还原字号与加粗，不套用 Word 标题样式，避免样式表副作用。
2. **有线表格识别**：从页面内容流路径元素中提取水平 / 垂直线段，聚类成网格包围盒；用词的包围盒与单元格求交完成 cell 归位，空单元格保留占位；表格作为一个版面块映射为 `XWPFTable`。识别条件从严：至少 2×2 条正交线围出至少两个格子才算表格，避免把下划线、装饰线误判为表格。
3. **图片提取**：页面位图图片经 `page.GetImages()` 提取；JPEG（DCTDecode）直接嵌入，其余受支持滤镜解码后转 PNG 嵌入，不支持的滤镜跳过并写日志（不中断导出）。
4. **块排序与写出**：段落块、表格块、图片块统一按页面 y 坐标排序后依序写出，页间仍保留分页符。

### 失败边界

- 表格识别、图片解码任何单页失败仅降级该页为纯文本段落并写日志，导出整体不失败；
- 全文档级别错误（文件损坏、加密）维持既有失败结果行为。

## 交互与异常

| 场景 | 处理 |
| --- | --- |
| 源文件损坏 / 加密 | 处理失败，展示可读原因 |
| 范围非法 | 解析阶段短路，展示具体原因，不产生输出文件 |
| 重复页码 / 乱序区间 | 去重排序后正常执行 |
| 处理中 | 进行中反馈，不阻塞界面 |
| 单页表格 / 图片解析异常 | 该页降级为纯文本并写日志，导出继续 |

## 验证方式

- 单元测试：`PdfPageRangeParser` 的合法 / 非法表达式用例（单页、区间、混合、越界、空值）。
- Word 还原度用例：测试内用 PdfSharp 生成含大字号标题 / 加粗 / 表格线 / JPEG 图片的 fixture PDF，导出 docx 后用 NPOI 回读断言（表格行列与单元格文本、图片存在、字号与加粗生效）。
- 手动 smoke：真实 PDF 分割后核对页数与内容；Word 导出可打开编辑且版面元素齐全。
