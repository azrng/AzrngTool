# 数据库工作台界面重设计（DES-DATABASE-001）

> 本文档由 `doc/design/设计文档.md`（原任务 T121）迁移而来，设计内容保留，仅按设计文档结构重组并补充编号；后续变更直接在本文件维护。

## 需求追溯

- 关联需求：`REQ-DATABASE-001`。
- 本次覆盖：数据库工作台主页面布局与信息层级、上下文栏、对象浏览器、欢迎态、对象详情页视觉一致性、窄窗口收起策略。
- 不覆盖：连接、查询、加载、导出、代码生成的业务规则与数据模型变更（与需求范围一致）。

## 技术设计

### 设计目标

将现有"顶部命令区 + 左侧对象树 + 首屏说明卡"的分散结构收敛为一个持续可感知的工作区。用户始终只需要关注三件事：当前连接上下文、正在浏览的对象、当前主操作。

视觉方向采用"克制的专业控制台"：低对比的结构分区、清晰的文字层级和紧凑而可预测的操作区；不增加装饰性大卡片或大段说明文案。

### 模块划分

| 模块 | 职责 | 复用现有能力 |
| --- | --- | --- |
| 上下文栏 | 展示并切换连接、数据库、架构；提供连接管理入口 | `MainWindowViewModel` 的连接与数据库绑定、连接管理命令 |
| 对象浏览器 | 搜索与浏览数据库对象，支持收起 | `DatabaseTree`、`DatabaseBrowserViewModel`、刷新命令 |
| 主工作区 | 承载欢迎态与对象详情 | 现有三类 Workspace 可见状态与详情 ViewModel |
| 工作区命令栏 | 保留当前工作区的高频操作，低频操作收纳至"更多操作" | 导出与生成命令 |
| 状态反馈 | 局部显示 loading、empty、error、no-permission | 已有加载与结果状态，按页面补齐可视表达 |

### 页面结构

1. 上下文栏
   - 左侧为页面名称；中部为"连接 / 数据库 / 架构"的连续选择器；右侧显示可读的连接状态。
   - "连接管理"作为单一明确入口；文档导出、pg_dump 导出、生成代码移入"更多操作"菜单。
   - 不重复展示"当前连接""当前数据库"的信息卡。

2. 对象浏览器
   - 固定为主页面的次级面板，默认宽度约 280px；只保留对象搜索、对象树和刷新按钮。
   - 数据库选择属于顶部上下文栏，不再占用对象浏览器空间。
   - 常规宽度下浏览器持续可见；紧凑宽度下可收起并以抽屉恢复。

3. 欢迎态
   - 取消大面积首屏概览、流程说明和对象统计卡。
   - 未连接时显示一个明确动作："选择连接"；已连接但未选择对象时显示当前上下文及连接管理入口。

4. 对象详情
   - 页面顶部只显示对象类型、名称、所属架构和与当前对象相关的操作。
   - 将列、索引、定义等信息按现有页签组织；保留编辑备注等已有能力。
   - 目录节点被选中时，显示对象列表或空态，不保留之前对象的详情。

### 数据与状态流向

```text
连接 / 数据库选择
        ↓
当前上下文（连接、数据库、架构）
        ├── 对象浏览器：加载、搜索、选择对象
        └── 主工作区：对象详情 / 欢迎态
                          ↓
                    局部加载、结果或错误反馈
```

界面层仅调整布局与信息呈现。连接切换、对象加载及各类导出仍复用现有 ViewModel、命令和服务；不增加平行状态或绕开 MVVM。

### 业务规则

- 不改变现有连接、数据库、架构切换的触发逻辑。
- "更多操作"中原有操作的可用性、数据库类型限制和提示保持不变。
- 窄屏布局只改变呈现形式，不隐藏任何可达操作。

### 关键状态

| 状态 | 表现 | 建议动作 |
| --- | --- | --- |
| 未连接 | 欢迎态提示未选择连接 | 选择连接、管理连接 |
| 未选对象 | 简洁工作区引导 | 浏览对象、管理连接 |
| 局部加载 | 对象树骨架 / 进度提示 | 可继续查看其他区域 |
| 空结果 | 说明没有可展示的对象 | 刷新、调整搜索 |
| 加载错误 | 人类可读错误与重试入口 | 重试、检查连接 |
| 无权限 | 明确的权限提示，区别于空态 | 检查连接账号权限 |

## 界面原型

### 常规宽度（≥ 1280px）

```text
┌ 数据库工作台 ── [连接 ▾] / [数据库 ▾] / [架构 ▾] ───────── [连接状态] [管理] [更多 ▾] ┐
├──────────── 对象浏览器 ───────────┬──────────────────────────── 主工作区 ───────────────────────────┤
│ [搜索对象................................] │ [对象类型]  schema.object_name                         [操作…] │
│ ──────────────────────────────────────── │   对象详情：列 / 索引 / DDL                                │
│ ▾ 表                                      │                                                               │
│   ├ users                                 │                                                               │
│   └ orders                                │                                                               │
│ ▸ 视图                                    │                                                               │
│ ▸ 存储过程                                │                                                               │
│ ──────────────────────────────────────── │                                                               │
│ [刷新]                                    │                                                               │
└──────────────────────────────────────────┴───────────────────────────────────────────────────────────────┘
```

### 欢迎 / 空 / 错误状态

```text
┌──────────────────────────────── 主工作区 ────────────────────────────────┐
│ 已连接到 PostgreSQL / app                                                  │
│ 选择左侧对象开始浏览。                                                      │
│ [管理连接]                                                                  │
│                                                                            │
│ 加载失败：无法读取对象树。 [重试] [检查连接]                               │
│                                                                            │
│ 无权限：当前账号没有查看 schema public 的权限。                            │
└────────────────────────────────────────────────────────────────────────────┘
```

### 紧凑宽度（< 960px）

```text
┌ 数据库工作台  [连接 / 数据库 ▾]                 [对象浏览器] [更多 ▾] ┐
├──────────────────────────────── 主工作区 ───────────────────────────────┤
│ 对象浏览器以左侧抽屉打开；关闭后主工作区保持完整宽度。                    │
└───────────────────────────────────────────────────────────────────────────┘
```

## 交互与异常

1. 选择连接后，上下文栏更新连接状态；数据库选择器加载可用数据库。未选择数据库时对象浏览器展示引导状态。
2. 选择数据库后，对象树加载；用户可在对象浏览器搜索、刷新。搜索仅过滤对象树，不影响当前连接上下文。
3. 选择具体对象后，主工作区更新为对应详情。选择"表 / 视图 / 存储过程"目录节点时切回列表态，不能保留旧详情。
4. "更多操作"使用现有对话框 / 抽屉打开导出与生成能力；操作结束后在当前页面给出明确结果反馈。
5. 在窗口宽度低于 960px 时，对象浏览器收为抽屉；窗口恢复后保持用户当前的浏览状态与选择对象。

## 验收标准

- 首屏不再出现连接 / 数据库重复信息卡、对象统计卡和流程说明卡。
- 所有已有高频操作都可在一个页面内访问，低频操作可通过"更多操作"访问。
- 用户能在不离开工作台的情况下完成连接选择、对象浏览和导出入口访问。
- 1280、1440、1920 及小于 960px 的窗口宽度下，主要操作不丢失、主工作区可读。
