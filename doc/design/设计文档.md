# 项目设计文档

## 数据库工作台界面重设计（T121）

### 架构设计

#### 设计目标

将现有“顶部命令区 + 左侧对象树 + 首屏说明卡 + 独立 SQL 卡片”的分散结构收敛为一个持续可感知的工作区。用户始终只需要关注三件事：当前连接上下文、正在浏览的对象、当前主操作。

视觉方向采用“克制的专业控制台”：低对比的结构分区、清晰的文字层级和紧凑而可预测的操作区；不增加装饰性大卡片或大段说明文案。

#### 模块划分

| 模块 | 职责 | 复用现有能力 |
| --- | --- | --- |
| 上下文栏 | 展示并切换连接、数据库、架构；提供连接管理入口 | `MainWindowViewModel` 的连接与数据库绑定、连接管理命令 |
| 对象浏览器 | 搜索与浏览数据库对象，支持收起 | `DatabaseTree`、`DatabaseBrowserViewModel`、刷新命令 |
| 主工作区 | 承载欢迎态、对象详情和 SQL 查询 | 现有四类 Workspace 可见状态与详情 ViewModel |
| 工作区命令栏 | 保留当前工作区的高频操作，低频操作收纳至“更多操作” | SQL 执行 / 清空 / 格式化、导出与生成命令 |
| 状态反馈 | 局部显示 loading、empty、error、no-permission | 已有加载与结果状态，按页面补齐可视表达 |

#### 数据与状态流向

```text
连接 / 数据库选择
        ↓
当前上下文（连接、数据库、架构）
        ├── 对象浏览器：加载、搜索、选择对象
        └── 主工作区：对象详情 / SQL 查询 / 欢迎态
                          ↓
                    局部加载、结果或错误反馈
```

界面层仅调整布局与信息呈现。连接切换、对象加载、SQL 执行、危险 SQL 确认及各类导出仍复用现有 ViewModel、命令和服务；不增加平行状态或绕开 MVVM。

### 功能需求

#### 页面结构

1. 上下文栏
   - 左侧为页面名称；中部为“连接 / 数据库 / 架构”的连续选择器；右侧显示可读的连接状态。
   - “连接管理”作为单一明确入口；文档导出、pg_dump 导出、生成代码移入“更多操作”菜单。
   - 不重复展示“当前连接”“当前数据库”的信息卡。

2. 对象浏览器
   - 固定为主页面的次级面板，默认宽度约 280px；只保留对象搜索、对象树和刷新按钮。
   - 数据库选择属于顶部上下文栏，不再占用对象浏览器空间。
   - “SQL 查询”升格为对象树上方或主工作区首要入口，避免与刷新、清空搜索并列造成误解。
   - 常规宽度下浏览器持续可见；紧凑宽度下可收起并以抽屉恢复。

3. 欢迎态
   - 取消大面积首屏概览、流程说明和对象统计卡。
   - 未连接时显示一个明确动作：“选择连接”；已连接但未选择对象时显示当前上下文及两个高频动作：“浏览对象”“新建查询”。

4. 对象详情
   - 页面顶部只显示对象类型、名称、所属架构和与当前对象相关的操作。
   - 将列、索引、定义等信息按现有页签组织；保留编辑备注等已有能力。
   - 目录节点被选中时，显示对象列表或空态，不保留之前对象的详情。

5. SQL 查询
   - 顶部命令栏从左到右为：当前上下文、模板 / 历史下拉、格式化、清空、主按钮“执行”。
   - SQL 编辑器为工作区主体；结果区固定在下方，可拖动或在窗口变矮时优先压缩编辑器。
   - 结果区标题呈现“结果 / 影响行数 / 执行反馈”，不再单独使用一张说明卡。
   - 结果为空、执行失败、执行中均在结果容器内反馈，保持编辑器可继续使用。

#### 业务规则

- 不改变现有连接、数据库、架构切换的触发逻辑。
- 不改变危险 SQL 的二次确认和执行结果处理。
- “更多操作”中原有操作的可用性、数据库类型限制和提示保持不变。
- SQL 查询仍使用当前连接与当前架构；模板占位符仍以当前架构替换。
- 窄屏布局只改变呈现形式，不隐藏任何可达操作。

#### 关键状态

| 状态 | 表现 | 建议动作 |
| --- | --- | --- |
| 未连接 | 欢迎态提示未选择连接 | 选择连接、管理连接 |
| 未选对象 | 简洁工作区引导 | 浏览对象、新建查询 |
| 局部加载 | 对象树或结果区骨架 / 进度提示 | 可继续查看其他区域 |
| 空结果 | 说明没有可展示的对象或结果集 | 刷新、调整搜索、执行查询 |
| 加载 / 查询错误 | 人类可读错误与重试入口 | 重试、检查连接 |
| 无权限 | 明确的权限提示，区别于空态 | 检查连接账号权限 |

### 界面原型

#### 常规宽度（≥ 1280px）

```text
┌ 数据库工作台 ── [连接 ▾] / [数据库 ▾] / [架构 ▾] ───────── [连接状态] [管理] [更多 ▾] ┐
├──────────── 对象浏览器 ───────────┬──────────────────────────── 主工作区 ───────────────────────────┤
│ [搜索对象................................] │ [对象类型]  schema.object_name                         [操作…] │
│ [+ 新建查询]                              │ ─────────────────────────────────────────────────────────── │
│ ──────────────────────────────────────── │   对象详情：列 / 索引 / DDL                                │
│ ▾ 表                                      │   或 SQL 编辑器与结果区                                     │
│   ├ users                                 │                                                               │
│   └ orders                                │                                                               │
│ ▸ 视图                                    │                                                               │
│ ▸ 存储过程                                │                                                               │
│ ──────────────────────────────────────── │                                                               │
│ [刷新]                                    │                                                               │
└──────────────────────────────────────────┴───────────────────────────────────────────────────────────────┘
```

#### SQL 查询工作区

```text
┌ 查询  PostgreSQL / app / public ── [模板 ▾] [历史 ▾] [格式化] [清空] [▶ 执行] ┐
├────────────────────────────────────────────────────────────────────────────────────────────┤
│  SELECT *                                                                                    │
│  FROM users;                                                                                 │
│                                                                                                │
├ 结果 ─────────────────────────────────────────────── 12 行 · 84 ms ──────────────────────────┤
│ id          name              created_at                                                      │
│ 1           ...               ...                                                             │
└──────────────────────────────────────────────────────────────────────────────────────────────┘
```

#### 欢迎 / 空 / 错误状态

```text
┌──────────────────────────────── 主工作区 ────────────────────────────────┐
│ 已连接到 PostgreSQL / app                                                  │
│ 选择左侧对象开始浏览，或直接执行一段 SQL。                                  │
│ [浏览对象]  [新建查询]                                                      │
│                                                                            │
│ 加载失败：无法读取对象树。 [重试] [检查连接]                               │
│                                                                            │
│ 无权限：当前账号没有查看 schema public 的权限。                            │
└────────────────────────────────────────────────────────────────────────────┘
```

#### 紧凑宽度（< 960px）

```text
┌ 数据库工作台  [连接 / 数据库 ▾]                 [对象浏览器] [更多 ▾] ┐
├──────────────────────────────── 主工作区 ───────────────────────────────┤
│ 对象浏览器以左侧抽屉打开；关闭后主工作区保持完整宽度。                    │
└───────────────────────────────────────────────────────────────────────────┘
```

### 交互说明

1. 选择连接后，上下文栏更新连接状态；数据库选择器加载可用数据库。未选择数据库时对象浏览器展示引导状态。
2. 选择数据库后，对象树加载；用户可在对象浏览器搜索、刷新或打开 SQL 查询。搜索仅过滤对象树，不影响当前连接上下文。
3. 选择具体对象后，主工作区更新为对应详情。选择“表 / 视图 / 存储过程”目录节点时切回列表态，不能保留旧详情。
4. 点击“新建查询”后，主工作区切换至 SQL 查询；模板、历史和格式化不覆盖未确认的 SQL 编辑内容。
5. 执行 SQL 时，编辑器保持可见，结果区域独立显示进度。成功时显示结果表或影响行数；失败时显示可理解错误与重试入口。危险 SQL 仍弹出二次确认。
6. “更多操作”使用现有对话框 / 抽屉打开导出与生成能力；操作结束后在当前页面给出明确结果反馈。
7. 在窗口宽度低于 960px 时，对象浏览器收为抽屉；窗口恢复后保持用户当前的浏览状态与选择对象。

#### 验收标准

- 首屏不再出现连接 / 数据库重复信息卡、对象统计卡和流程说明卡。
- 所有已有高频操作都可在一个页面内访问，低频操作可通过“更多操作”访问。
- 用户能在不离开工作台的情况下完成连接选择、对象浏览、SQL 执行和导出入口访问。
- SQL 页同时保留编辑、执行反馈和结果浏览，空、加载、错误状态均可理解。
- 1280、1440、1920 及小于 960px 的窗口宽度下，主要操作不丢失、主工作区可读。
