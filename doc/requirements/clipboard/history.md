# 剪贴板历史管理（REQ-CLIPBOARD-001）

> 状态说明：2026-09-12 用户决定暂缓本功能（先不做，后续再做）。文档保留为后续恢复的基础，恢复开发时需重新确认后转 `approved` 才能进入阶段 1。

## 项目背景

Windows 系统剪贴板一次只保留最后一次复制的内容，用户在开发与日常操作中经常需要在多处复制粘贴，中途内容被覆盖后只能回到源头重新复制。Windows 自带的 Win+V 历史虽然提供了基础的多条记录能力，但检索能力弱、无法按内容类型分类管理、也无法与开发工具箱场景结合。

AzrngTools 定位为开发与效率场景的桌面工具箱，剪贴板历史管理属于同一目标下的自然模块。

## 目标与范围

在应用内提供剪贴板历史管理模块：应用运行期间自动记录复制内容，用户可在统一页面中搜索、固定、分类查看，并把历史条目快速复制回剪贴板。

本次范围：

- 应用运行期间自动采集剪贴板内容，不依赖剪贴板页面是否打开；
- 支持纯文本、图片、文件（复制/剪切的文件路径列表）三类内容；
- 历史列表支持关键字搜索、按类型过滤、固定常用条目；
- 单条操作：复制回剪贴板、固定 / 取消固定、删除、查看图片大图、打开文件所在位置；
- 提供采集暂停开关与"清空未固定历史"操作；
- 历史数据仅保存在本机用户目录。

不在本次范围（列入后续版本评估）：

- 系统托盘常驻、全局热键呼出、悬浮快捷面板、开机自启；
- 忽略指定应用（如密码管理器）的采集排除规则；
- 富文本 / HTML / RTF 格式内容的保留与还原；
- 图片内容 OCR 搜索；
- 历史数据加密存储与跨设备同步；
- 保留策略的自定义设置界面（首版使用固定默认值）。

## 用户角色

- 开发人员：在文档、代码、接口调试之间频繁复制粘贴代码片段、连接串、URL 等文本。
- 一般桌面用户：日常复制文件、截图、文本，希望找回近期复制过的内容。

## 页面清单

- 剪贴板历史页（主窗口内单个模块页，含列表区、搜索区、固定区）。

## 核心业务流程

1. 自动采集：用户在系统任意应用中复制内容，应用在运行期间自动记录，同一内容重复复制时不产生重复条目，仅刷新时间并置顶。
2. 查看与检索：用户进入剪贴板历史页，可按关键字搜索、按类型（全部 / 文本 / 图片 / 文件）过滤浏览历史。
3. 使用历史：用户选中条目后复制回系统剪贴板继续粘贴；图片条目可查看大图；文件条目可打开所在文件夹。
4. 整理：用户可固定常用条目使其不受清理影响，可删除单条，可一键清空全部未固定历史。
5. 自动清理：未固定条目按数量上限、时间期限与图片容量上限自动淘汰，固定条目不受影响。

## 关键业务对象及字段含义

- 剪贴板条目：
  - 类型：文本 / 图片 / 文件，单次复制按"文件 > 图片 > 文本"优先归类为一种类型；
  - 内容：文本原文（超长截断存储）、图片文件引用、文件路径列表；
  - 时间：首次复制时间、最近复制时间；
  - 固定状态：已固定 / 未固定；
  - 大小信息：文本字符数或图片尺寸，用于列表预览展示。

## 权限与可见范围

本机单用户使用，不引入权限控制；历史数据仅存于当前用户目录，不上传任何网络服务。

## 边界场景与异常

- 单条文本超过存储上限时截断存储并标记，超大文本不入库；
- 图片累计占用超过容量上限时，按最久未使用自动清理未固定图片；
- 未固定条目超过保留期限后自动过期清理；
- 用户开启暂停采集后，期间复制内容不入库，恢复后仅记录新内容；
- 剪贴板被其他程序占用或内容在读取间隙变化时，跳过该次采集，不影响后续监听；
- 图片缓存文件丢失时，条目显示占位并提供删除入口；
- 文件条目指向的源文件被移动或删除时，仍保留路径记录供查看；
- 历史数据文件损坏时，从空历史重建，不阻塞应用启动。

## 非功能要求

- 采集过程用户无感知：轮询开销可忽略，不独占、不阻塞系统剪贴板；
- 几百条规模下列表滚动、搜索响应流畅；
- 隐私：数据仅落本机；提供暂停采集开关，敏感内容可随时手动删除；
- 应用启动时加载历史不产生可感知的启动延迟。

## 验收标准

1. 应用运行期间复制文本 / 图片 / 文件，剪贴板历史页均出现对应类型条目，重复复制同一内容不产生重复条目。
2. 搜索关键字可命中文本内容与文件路径，图片条目不参与文本搜索。
3. 固定条目始终展示在固定区，清空与自动清理均不影响固定条目。
4. 双击或操作按钮可将条目内容还原到系统剪贴板，粘贴行为与原始内容一致（图片为位图、文件为文件列表）。
5. 超过数量上限或保留期限的未固定条目被自动清理，对应图片文件一并删除。
6. 开启暂停采集后新的复制不入库，关闭后恢复采集。
7. 删除单条 / 清空历史后，历史数据文件与图片缓存保持一致，无孤儿图片残留。
8. 历史数据文件被人为破坏后，应用可正常启动并从空历史重建。

## 待确认项

1. 首版默认保留策略：未固定 500 条、保留 30 天、图片缓存上限 200MB、单条文本截断 32KB、超过 256KB 不入库——是否接受（影响存储与清理实现的默认参数）。
2. 入口位置：剪贴板历史在主窗口导航中的分组归属（影响导航配置，不阻塞设计）。
3. 图片条目搜索：首版不支持 OCR 检索，是否接受。
