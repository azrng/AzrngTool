# PDF 导出 Markdown（REQ-PDF-002）

## 项目背景

接口文档、学术论文、产品手册常以 PDF 形态流转，而知识库归档、README 与大模型输入需要 Markdown。Word 转 Markdown（`REQ-WORD-001`）已覆盖 docx 输入，PDF 输入尚属空白；在线转换器需上传文件存在隐私顾虑，通用命令行工具（pandoc）对普通用户不友好。在既有 PDF 管理能力（分割、导出 Word）基础上增加「导出 Markdown」，全程本地完成。

## 目标与范围

在 PDF 管理页为当前载入的 PDF 新增「导出 Markdown」能力：转换为 Markdown 文本并写出 .md 文件，内嵌图片可导出到 md 同级资源目录；图片型（扫描件）PDF 不转换，给出明确提示。

本次范围：

- 在 PDF 管理页新增「导出 Markdown」功能区：输出路径选择、图片导出模式开关、开始转换命令；
- 标题层级判定，判定来源按优先级：文档大纲书签 → 结构化标签 → 视觉字号推断；
- 加粗、斜体文本还原；超链接还原为 Markdown 链接；
- 有线表格还原为 GFM 表格；
- 图片处理两种模式：导出到 `<md 文件名>.assets/` 目录并以相对路径引用（默认），或忽略图片；
- 图片型 PDF（无可提取文本）转换时直接提示不支持，不产生输出文件；
- 转换完成后按既有反馈方式提示输出路径、标题数与图片数（页面不设 Markdown 预览区，与分割 / 导出 Word 反馈口径一致）。

不在本次范围：

- Markdown 预览区（页面空间约束，并入现有页面）；
- 扫描件 OCR（图片型内容不还原）；
- 无线表格、三线表（学术论文常用无竖线样式）的表格还原；
- 加密 PDF 解密（与既有导出 Word 行为一致，按失败处理）；
- 批量多文件处理；
- .md 反向转 PDF。

## 用户角色

- 开发人员：把接口文档、论文、设计说明的 PDF 版转成 Markdown 归档知识库。
- 一般办公用户：把现有 PDF 资料转为 Markdown 用于发布或协作。

## 页面清单

- PDF 管理页新增「导出 Markdown」功能区（不新增页面，复用既有文件载入与处理状态区）。

## 核心业务流程

1. 用户在 PDF 管理页选择 PDF 文件（复用既有载入，展示文件名、大小、页数，自动填充默认 .md 输出路径）。
2. 用户确认 .md 输出路径与图片处理方式（默认：导出图片到同名 .assets 目录）。
3. 用户执行「导出 Markdown」，完成后提示输出路径、识别标题数与导出图片数。
4. 图片型 PDF（无可提取文本）时提示不支持，不产生输出文件。
5. 失败时展示可读原因，不产生输出文件。

## 关键业务对象及字段含义

- 源文件：当前载入的本地 PDF（复用既有载入状态，不重复选择）；
- 输出目标：.md 输出路径，默认取源文件同名 .md；
- 图片模式：导出（图片落盘 `<md 名>.assets/`，md 内写相对引用）或忽略（图片整体丢弃，md 内不出现图片引用）；
- 图片型 PDF：内容以图片为主、没有可提取文字层的 PDF（典型为扫描件），判定为转换前拒绝；
- 转换结果：输出路径、识别标题数、导出图片数。

## 权限与可见范围

本机单用户使用，不引入权限控制；仅读写用户指定的本地文件与输出目录。

## 边界场景与异常

- 图片型 PDF：转换前判定并提示「无可提取文本」，不产出任何文件；
- 混合文档（部分页面为图片）：有文字页正常转换，纯图片页内容跳过（该页不产出文本），整体不失败（v1 口径，不做逐页提示）；
- 无大纲书签且无结构化标签的 PDF：标题按视觉字号推断，推断不出的行按普通段落输出；
- 输出路径为空时提示，不进入转换；
- 源文件损坏或加密导致解析失败时，与既有导出 Word 一致展示失败原因。

## 非功能要求

- 本地处理，文件不上传；
- 不引入新依赖、外部进程（pandoc）或商业授权组件；
- 大文件转换期间给出进行中反馈，不阻塞界面。

## 验收标准

1. 带大纲书签的 PDF（中英文均含）转换后标题层级与书签层级一致。
2. 无书签、无标签的 PDF 按视觉字号产出标题；行号、上标、装饰字符等短行不误判为标题。
3. 加粗、斜体在输出中语义正确；超链接输出为 `[文本](地址)` 形式。
4. 有线表格转换为 GFM 表格，单元格内换行合并、竖线转义。
5. 默认模式下内嵌图片导出到 `<md 名>.assets/` 目录，md 内为相对路径引用；忽略模式下 md 内无图片引用且不产生 assets 目录。
6. 图片型 PDF 转换给出明确提示，不产生输出文件。
7. 全程无网络上传行为。

## 待确认项

1. 混合文档的纯图片页跳过时不在结果中逐页提示，仅整体统计口径（v1 从简）；若实测反馈需要，后续加「跳过页数」统计。
2. 图片型判定阈值与字号标题判定参数以实现期真实样本实测为准（调研阶段已有三样本基线），实现落地后在设计文档记录最终取值。
