# 设置与应用管理（REQ-SETTINGS-001）

> 本文档为依据当前实现整理的回溯基线，待用户确认后转为 approved。

## 项目背景

工具箱作为常驻使用的桌面应用，需要覆盖应用级的基础体验：查看本机硬件信息、了解当前版本并保持更新、记住亮暗主题偏好、把高频工具放到手边。这些能力统一收敛在"系统设置"分组与应用框架中。

## 目标与范围

本次范围：

- 硬件信息页：展示本机系统与硬件信息概览，采集结果本地缓存避免重复采集；
- 关于页：展示版本信息，提供"检查更新"与"立即更新"入口；
- 应用自动更新：读取 GitHub Release 最新版本，下载便携版更新包，退出后自动覆盖安装并重启；
- 主题偏好：亮色 / 暗色主题切换，立即生效并持久化，重启保持；
- 侧栏常用入口：按使用频率与最近使用情况推荐常用工具（最多 3 个）。

不在本次范围（如需再做评估）：

- 多语言界面；
- 设置中心页（当前设置能力分布在硬件信息与关于页）；
- 更新通道选择（灰度 / Beta）。

## 用户角色

- 所有用户：主题偏好、常用入口属于全局体验；
- 开发人员：硬件信息用于了解运行环境；
- 所有用户：通过关于页保持版本更新。

## 页面清单

- 硬件信息页（导航分组"系统设置"）；
- 关于页（导航分组"系统设置"）；
- 侧栏常用入口（主窗口框架内，非独立页面）。

## 核心业务流程

1. 硬件信息：打开页面 → 优先读取本地缓存，必要时重新采集 → 展示概览。
2. 主题：切换亮 / 暗 → 界面立即切换 → 偏好写入本机，下次启动按偏好加载。
3. 检查更新：应用启动时后台自动检查，用户也可在关于页手动检查 → 发现新版本时展示版本信息 → 用户确认后下载更新包 → 下载完成后提示应用 → 退出后自动覆盖安装并重启。
4. 常用入口：每次打开工具累计使用记录 → 侧栏按评分推荐最常用工具。

## 关键业务对象及字段含义

- 版本信息：当前版本号与最新版本号，统一使用可比较的数字版本号；兼容识别旧三段 / 四段时间版本；
- 更新包：固定命名 `AzrngTools-win-x64-portable.zip` 的便携版压缩包；
- 主题偏好：亮色 / 暗色；
- 使用记录：工具标识、使用次数、最近使用时间。

## 权限与可见范围

本机单用户使用，无权限控制。更新检查与下载访问 GitHub Release；硬件信息仅在本机展示与缓存。

## 边界场景与异常

- 当前已是最新版本时，明确提示无需更新；
- 检查或下载失败时给出可读原因，可重试；下载失败后不反复自动重试；
- 安装目录无写入权限导致无法自动覆盖时，引导用户手动下载 Release 压缩包覆盖；
- 硬件信息采集失败或缓存损坏时，可重新采集，不阻塞页面；
- 偏好文件损坏时按默认主题启动，不阻塞应用。

## 非功能要求

- 更新版本号随发布严格递增，保证客户端比较语义正确；
- 启动自动检查更新不得产生可感知的启动延迟；
- 主题切换即时生效，不重启应用；
- 使用统计与偏好数据仅落本机。

## 验收标准

1. 亮暗主题切换立即生效，重启后保持所选主题。
2. 关于页正确展示当前版本；有新版本时能检查到并完成"下载 → 退出覆盖 → 重启"的更新闭环。
3. 安装目录不可写时给出手动更新引导。
4. 高频使用的工具出现在侧栏常用入口，且不超过 3 个。
5. 硬件信息页展示本机概览，二次打开不再重复完整采集。

## 待确认项

1. 硬件信息页展示字段范围以当前实现为准，需核对后补充清单。
2. 是否需要独立的设置中心页承载未来更多偏好项。
