# 页面输入记忆存档（REQ-SETTINGS-002）

## 项目背景

工具箱各工具页（格式互转、正则、SQL 格式化、接口调试等）是高频复用场景，但页面输入在应用重启后清零，用户需要重新粘贴或重新构造输入，重复成本高。用户明确提出：页面必要的用户输入应当被记住，与应用数据存放在同一目录。

本需求与需求索引既有约束「工具页不持久化用户输入」（隐私优先基线）冲突，属于对该约束的显式修订：记忆是用户要求的便利能力，同时保留隐私底线——敏感字段（密钥、令牌、凭证）一律不落盘，且数据只存本机应用数据目录，不出本机。

## 目标与范围

本次范围：

- 内容输入记忆：工具页的主要文本输入（源文本、待转换内容等）在应用重启后自动恢复；
- 选项记忆：工具页的选项状态（格式选择、算法选择、开关、页码范围、输出路径等）重启后保持；
- 主窗口状态：记住上次打开的工具页与侧栏折叠状态；
- 存储位置：与主题偏好、工具使用统计等其他应用数据同目录（`%LOCALAPPDATA%\AzrngTools\`）；
- 敏感字段排除：加密密钥、RSA 密钥对、JWT 明文、接口请求头/请求体等凭证类输入不存档。

不覆盖：

- 日志文件位置迁移（已由 T037 完成，日志已落 `%LOCALAPPDATA%\AzrngTools\logs\`）；
- 工具使用统计、接口调试历史记录等既有持久化能力；
- 设置页新增记忆开关界面（见待确认项）。

## 用户角色

单机本地开发者用户，无账号与权限体系，数据不出本机。

## 页面与模块清单

| 分组 | 接入页面 | 说明 |
| --- | --- | --- |
| 编码解码 | Base64、Base64 转图片、繁简转换、组合工作台、Gzip、Hex、Unicode、URL | 记内容输入；Hex 另记格式与分隔符选项 |
| 生成与加密 | AES、DES、哈希、HMAC、RSA、SM4、JSON Schema、JSON 转 C#、密码生成 | 加密页记内容输入与算法选项；密码生成只记生成规则选项 |
| 格式化 | JSON、JSON/YAML/XML/ENV 互转、MIME 查询、正则、SQL 格式化、字符串、字数统计、XML 转 HTML | 记内容输入与格式/正则选项 |
| 接口调试 | API 请求页 | 记 URL、方法、Body 模式、页签索引、SSL 开关；请求头/查询/表单值与请求体排除 |
| 其他 | 翻译、Unix 时间戳 | 记内容输入与转换方向选项 |
| PDF | PDF 管理 | 记页码范围、分割模式、两个输出路径 |
| 主窗口 | — | 记上次打开页面、侧栏折叠状态 |

明确不接入：JWT 解析页（唯一输入为令牌明文）、人民币大写（无记忆价值）、GUID 生成（无输入）、关于页与硬件页（纯展示）。

## 核心业务流程

1. 用户打开某个工具页：若存在该页的存档，输入框与选项自动恢复为上次离开时的状态；无存档时维持现有默认值。
2. 用户编辑输入或切换选项：变更在短延迟内自动写入本机存档，无手动保存动作。
3. 用户重启应用：打开页面即为上次状态；主窗口自动回到上次打开的工具页。

## 关键业务对象及字段含义

页面输入快照（每页一份，业务含义层面）：

- 页面标识：页面的稳定标识，决定存档归属；
- 输入键值：页面声明需要记忆的字段（输入内容、选项）与其当前值；
- 更新时间：最后一次保存时间，仅用于诊断。

## 权限与可见范围

无账号体系；存档只存当前 Windows 用户的应用数据目录，不跨用户、不出本机。

## 边界场景与异常

- 首次使用：无存档文件，页面维持现有默认值，不报错；
- 存档损坏（文件被手工改坏、磁盘异常）：该页存档整体丢弃，页面维持默认值，记录错误日志，不影响页面功能；
- 超大输入：单字段超长（如数 MB 文本）时该字段跳过存档，其余字段正常保存，记录日志；
- 敏感字段：无论用户是否输入，密钥/令牌/凭证类字段永不写入存档文件；
- 进程快速退出：最近的变更在退出时有机会落盘，极端情况下丢失最后不足一秒的变更（可接受）；
- 重置：删除存档目录即可恢复全部页面默认状态。

## 非功能要求

- 保存不得阻塞 UI 线程（异步 + 防抖合并连续键入）；
- 序列化需兼容发布链路的裁剪约束（源生成，不用反射序列化）；
- 单页存档文件保持小体积（KB 级选项 + 截断保护的内容）；
- 恢复过程用户无感知，无加载动画需求（文件小、读取快）。

## 验收标准

1. 任一接入页面输入内容与选项后重启应用，重新打开该页面，输入与选项恢复；主窗口回到上次页面；
2. 加密页输入密钥后重启：内容输入与算法选项恢复，密钥字段为默认值（密钥未落盘，存档文件中不存在该键）；
3. 手工破坏某页存档文件后启动应用：页面正常打开为默认值，日志中出现错误记录，其他页面存档不受影响；
4. 连续快速键入不产生每键一次的磁盘写入（防抖生效）；
5. 全解决方案构建 0 错 0 警告，测试全绿，新增存储服务有单元测试（临时目录注入，不读写真实用户数据）。

## 待确认项

1. 是否需要在设置界面提供「记住输入」开关（当前方案：不设开关，删除存档目录即重置）；
2. 接口调试页的请求体是否记忆（当前方案：不记，请求体可能含凭证）；
3. 保存防抖时长默认 800ms 是否合适。
