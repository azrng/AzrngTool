# 其他工具（REQ-MISC-001）

> 本文档为依据当前实现整理的回溯基线，待用户确认后转为 approved。

## 项目背景

除数据库、接口、编码格式类工具外，开发与日常使用中还有少量独立的高频小工具：Unix 时间戳与日期时间的互相换算、中英文翻译。它们不足以各自成模块，统一收纳在"其他"分组。

## 目标与范围

本次范围（导航分组"其他"）：

| 工具页 | 职责 |
| --- | --- |
| Unix 时间戳 | Unix 时间戳与日期时间双向换算 |
| 翻译 | 中英文互译（基于 Yandex 翻译，在线服务） |

不在本次范围（如需再做评估）：

- 更多语言对翻译；
- 时区换算、倒计时等扩展时间工具。

## 用户角色

- 开发人员：换算日志时间戳、查阅接口文档中的外文内容。

## 页面清单

上表两个工具页，每页为独立模块页。

## 核心业务流程

1. Unix 时间戳：输入时间戳或日期时间，页面即时换算另一侧结果并复制。
2. 翻译：输入中文或英文文本，点击翻译后展示译文；翻译通过在线服务完成，需要网络。

## 关键业务对象及字段含义

- 时间戳换算：时间戳值（精度以页面实现为准）与日期时间值的双向映射；
- 翻译：源文本（中文或英文）与译文。

## 权限与可见范围

本机单用户使用，无权限控制。时间戳换算纯本地；翻译依赖外部翻译服务的可达性。

## 边界场景与异常

- 非法时间戳或日期格式给出可读提示；
- 翻译服务不可达或失败时，明确提示失败原因，输入内容保留可重试；
- 空输入提示补全。

## 非功能要求

- 时间戳换算为本地即时计算；
- 翻译请求不阻塞界面，输入内容仅提交给翻译服务用于翻译本身。

## 验收标准

1. 时间戳与日期时间双向换算结果正确。
2. 中英互译在联网状态下返回合理译文，失败时有可读提示。
3. 结果可一键复制。

## 待确认项

1. 时间戳支持的精度（秒 / 毫秒）以页面实现为准，需核对后补充。
2. 翻译是否需要扩展更多语言对（当前实现聚焦中英互译）。
