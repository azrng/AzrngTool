# 生成与加密工具组（REQ-GENERATION-001）

> 本文档为依据当前实现整理的回溯基线，待用户确认后转为 approved。

## 项目背景

日常开发频繁需要：生成 GUID 标识、计算哈希摘要、执行对称 / 非对称加解密、由 JSON 推导 Schema 或实体类代码、生成高强度密码。使用在线工具需要把内容（可能包含敏感数据）粘贴到外部网站，存在泄露风险且无法离线使用。工具箱将这类高频计算收拢为本地工具组，输入不出本机。

## 目标与范围

提供十个独立工具页，覆盖标识生成、摘要计算、加解密与代码生成场景，全部为本地即时计算。

本次范围（导航分组"生成类工具"）：

| 工具页 | 职责 |
| --- | --- |
| GUID 生成器 | 批量生成 GUID |
| HASH | 计算文本哈希摘要 |
| HMAC HASH | 计算带密钥的哈希摘要 |
| AES | AES 对称加解密 |
| DES | DES 对称加解密 |
| SM4 | 国密 SM4 对称加解密 |
| RSA | RSA 密钥对生成与非对称加解密 |
| Json Schema 生成 | 由 JSON 生成 JSON Schema |
| JSON 转 C# 实体类 | 由 JSON 生成 C# 实体类代码 |
| 密码生成器 | 按长度与字符集生成随机密码 |

不在本次范围（如需再做评估）：

- 文件级（非文本）加解密；
- 证书管理与签名验签工具；
- 其他国密算法（SM2 / SM3）。

## 用户角色

- 开发人员：生成测试数据、计算签名摘要、加解密配置片段、生成契约与实体代码。

## 页面清单

上表十个工具页，每页为独立模块页。

## 核心业务流程

每个工具页为统一的单页流程，无跨页流转、无持久化：

1. 填写输入内容与选项（算法、密钥、格式等）；
2. 点击生成 / 加密 / 解密等动作，页面即时计算；
3. 查看输出结果并复制使用；
4. 输入非法时给出可读提示，不输出错误结果。

## 关键业务对象及字段含义

- GUID 生成器：生成数量与格式选项，输出 GUID 列表；
- HASH / HMAC：输入文本、算法选择；HMAC 额外需要密钥；输出十六进制摘要；
- AES / DES / SM4：明文 / 密文、密钥、IV 及模式选项（支持范围以页面为准），输出 Base64 或十六进制结果；
- RSA：密钥对（公钥 / 私钥）、加密用公钥、解密用私钥；
- Json Schema / JSON 转 C#：输入 JSON 文本与生成选项，输出 Schema 或 C# 代码；
- 密码生成器：长度、字符集（大小写字母 / 数字 / 符号）选项，输出随机密码。

具体算法与选项支持范围以各页面当前实现为准，差异项见待确认项。

## 权限与可见范围

本机单用户使用，无权限控制；计算全部本地完成，加解密输入与密钥不经过网络。

## 边界场景与异常

- 输入为空时提示补全，不执行计算；
- 密钥长度与算法要求不符、JSON 格式非法等输入错误，给出具体可读原因；
- 解密失败（密钥或数据不匹配）时明确报错，不输出乱码结果；
- 各工具页互不影响，单页异常不影响其他页面。

## 非功能要求

- 本地即时计算，常规规模输入下无明显等待；
- 工具页不持久化用户输入与输出（无本地文件残留）；
- 密码生成使用安全随机来源（以实现为准）。

## 验收标准

1. 各工具对已知标准向量的计算结果正确（如标准 SHA-256 摘要、AES 标准向量可对照）。
2. 空输入与非法参数均有可读提示，不产生错误结果。
3. 所有输出可一键复制。
4. 全程无网络请求。

## 待确认项

1. 各加密页支持的算法、工作模式与密钥长度清单，需逐页核对实现后补充。
2. GUID 生成的格式选项范围（大小写、有无连字符、花括号等）。
3. HASH / HMAC 支持的算法清单。
